# WHAT THE GOLF? — Standalone 1:1 Android Port & Security Audit (v20.5.34)

## Overview
Standalone offline 1:1 Android port and cryptographic security audit of **WHAT THE GOLF?** (`com.thelabelgames.golf` v20.5.34, build `261023.11511`, Unity `2020.3.49f1` ARM64 IL2CPP metadata v27.1).

- [`security-audit/`](security-audit/README.md) — Cryptographic code-signature, Apple CMS certificate-chain, `CodeResources` seal, ZIP container, and static 142,790-method IL2CPP cross-reference audit of `whatthegolf-20.5.34.ipa` (**verdict: no backdoor found**).
- [`android-port/`](android-port/) — Full 1:1 Unity Android port: all **336 scenes**, **16 episodes / content packs**, **169 `LevelData` assets**, reconstructed OpenGLES3/Vulkan/Metal `CGPROGRAM` shaders, decompiled `Triband.*` & `Assembly-CSharp` runtime/gameplay assemblies, offline `SaveGame` persistence, touch slingshot + gamepad controls, `WTGPortCatalog`, `WTGPortRuntime`, and `WTGAndroidBuilder`.

## Architecture of the 1:1 Android Port (`android-port/`)

### 1. Full Asset & Scene Decoding across All 84 Addressables Bundles
The iOS build stores the bootstrap scene (`_Start.unity`) in `Data/level0` and packs the remaining **335 scenes** and **21,249 assets** across 84 stripped-version (`0.0.0`) Addressables bundles under `Data/Raw/aa/iOS/*.bundle` (plus 11 On-Demand Resource tags in `OnDemandResources.plist`).
- `android-port/tools/run_export.sh` runs `AssetRipper 2.0.0` with `DefaultVersion=2020.3.49f1`, decoding **100% of the 21,249 assets and all 336 `.unity` scenes** with zero unreadable objects.
- `android-port/ProjectSettings/EditorBuildSettings.asset` and `Assets/Resources/WTGPortCatalog.asset` (generated by `android-port/tools/build_catalog.py`) register all **336 scenes**, **16 episodes** (`CP_MAIN_ONBOARDING`, `CP_MAIN_CAMPAIGN`, `CP_DAILY_CHALLENGE`, `CP_EPISODESHUB`, `CP_IMPOSSIBLE_LIVING_ROOM`, `CP_SPORTY_SPORTS`, `CP_SHOW_TO_A_FRIEND`, `CP_SNOWY_SNOW`, `CP_SECOND_ONBOARDING`, `CP_HOTDOG`, `CP_SPECIAL_EVENT`, `CP_AMONGUS`, `CP_ALIVE`, `CP_IMPOSSIBLE_LIVING_ROOM_EASY/MEDIUM/HARD`), and **169 `LevelData` assets**.

## Reproducing the Export & Building the Android APK

```bash
# 1. Export all 21,249 assets and 336 scenes from whatthegolf-20.5.34.ipa using AssetRipper 2.0.0
bash android-port/tools/run_export.sh

# 2. Sync ported scripts, reconstructed shaders, WTGPortCatalog, and Android ProjectSettings
python3 android-port/tools/prepare_unity_project.py /home/ubuntu/c113work/ar_out/ExportedProject

# 3. Build WhatTheGolf-Android.apk in Unity batchmode
/opt/unity/Editor/Unity \
  -batchmode -nographics -quit \
  -projectPath /home/ubuntu/c113work/ar_out/ExportedProject \
  -executeMethod WTGAndroidBuilder.BuildAll \
  -logFile /tmp/unity-wtg-android-build.log
```
